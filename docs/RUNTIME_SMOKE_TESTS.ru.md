# Runtime Smoke Tests

Runtime smoke-тесты запускают настоящий NeoForge runtime. Они дополняют компиляцию и JUnit, но не заменяют ручную проверку игрового процесса, сочетаний модов, целостности сохранений и производительности.

## Что проверяется

### Выделенный сервер

Тест запускает отдельную конфигурацию `runSmokeServer` на Windows и Linux. Для неё используется временная директория `runs/smoke-server`, отдельный EULA-файл, принимаемый только внутри этой тестовой директории, и небольшая локальная тестовая конфигурация с сокращённой дальностью прорисовки и симуляции.

Тест считается успешным, только если:
- общий entrypoint Fiximizer сообщает о начале загрузки;
- сервер достигает штатного сообщения `Done`;
- сервер принимает команду консоли `stop` и завершается с кодом 0.

Игровой сервер привязывается только к loopback и использует отдельный тестовый порт. Для остановки создаётся одноразовый случайный пароль RCON; сам RCON также доступен только через loopback. Подключение к публичным серверам не выполняется.

### Клиент

Тест Linux-клиента запускает отдельную конфигурацию `runSmokeClient` под Xvfb. Успех подтверждается, только если:
- клиентский entrypoint Fiximizer регистрирует панель управления;
- клиент достигает главного меню и фиксирует 40 стабильных клиентских тиков;
- тест отправляет окну событие закрытия, после чего Gradle runtime завершается с кодом 0.

Это подтверждает реальный запуск клиентского event subscriber и выполнение отложенного этапа запуска.

## Локальный запуск

Выделенный сервер (Windows или Linux):

```shell
python scripts/runtime_smoke.py server
```

Клиент под Linux с установленными Xvfb и xdotool:

```shell
xvfb-run -a -s "-screen 0 1280x720x24" python3 scripts/runtime_smoke.py client
```

Gradle-конфигурации используют отдельные каталоги внутри `runs/`; созданные миры, EULA, логи и клиентские настройки не попадают в git.

## Границы проверки

Успешный smoke-тест доказывает, что поддерживаемая CI-среда может запустить Fiximizer и завершить проверяемый путь старта/остановки. Он не подтверждает совместимость со всеми сторонними модами, сетевое подключение к multiplayer, прирост FPS, снижение памяти или качества сети и не заменяет ручной запуск мира и игровой сессии. Это отдельные критерии приёмки.
